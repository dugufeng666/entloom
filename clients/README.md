# Generated clients

The JavaScript, Java and Python clients in this directory are generated from
`server/src/main/resources/openapi/entloom.yaml` with OpenAPI Generator 7.10.0.

The runtime contract is generated by Springdoc and is available at
`/api/v1/openapi.yaml`. The complete install, authentication, regeneration and
package publishing guide is in [`docs/openapi-clients.md`](../docs/openapi-clients.md).

After starting the server, refresh the checked-in contract and regenerate clients:

```bash
./scripts/refresh-openapi.sh
./scripts/generate-clients.sh
```

Generated output should be committed together with contract changes so external
integrators can pin a repository revision.
